WEEKLY READINGS — WEEK 21 — PROMPTS PARA CHATGPT (UNA IMAGEN POR PROMPT)
==============================================================================

CÓMO FUNCIONA (resumen exacto del método usado en Weeks 12–20)
1. Un chat NUEVO de ChatGPT por cada imagen (evita que se trabe a partir del 2.º prompt).
2. En cada chat adjunto las fotos de referencia del grado (portada + page1 base) y pego UN solo prompt de este archivo.
3. Cada prompt empieza con "Generate the image now:" y contiene, en este orden: formato 4:5 vertical -> estilo del grado (ver bloque de estilo) -> escena concreta con los personajes bloqueados -> regla de texto.
4. Páginas interiores: CERO texto visible (sin letras, números ni logos). Portadas: SOLO el título exacto y, abajo, dos líneas: "Jony Rojas Ochoa" / "Reading Project shared by IEGRM".
5. Reviso cada imagen (personajes consistentes, sin texto, sin duplicados) y la convierto en el navegador a WEBP 1122x1402 con el nombre exacto del JSON (week21_gradeXX_cover.webp / week21_gradeXX_pageNN.webp).
6. Al terminar los 6 grados: ZIP por grado (Week21_Grade06_READY.zip ... Week21_Grade11_READY.zip) con solo las WEBP de ese grado, guardados en C:\xampp\htdocs\weeklyreadings.com\public\assets\images
NOTA HONESTA: ChatGPT no puede descargar archivos en tu disco por sí mismo; las descargas las hago yo desde el navegador (con retraso de varios minutos hasta que aparecen en la carpeta) y yo armo los ZIP.

CÓMO CONSTRUYO CADA PROMPT A PARTIR DEL JSON
- "artDirection" del JSON da el ESTILO por grado (Pixar-like 3D / painterly / semi-realista / realista). Lo condenso en un "bloque de estilo" fijo y lo repito idéntico en TODAS las imágenes del grado.
- "Scene based on:" del JSON da el ARGUMENTO por página (situación, presión, pistas, acción, comparación Nueva York, consecuencia, reflexión, reto de lectura). Lo traduzco a UNA escena visual concreta con los personajes del grado, sin palabras escritas.
- Personajes del JSON (p. ej. Juan/María) se bloquean con edad, peinado y ropa fija; se repiten textualmente en cada prompt.
- Se elimina cualquier concepto abstracto que ChatGPT pintaría como texto (chats, carteles, pantallas): las pantallas muestran solo íconos/formas.

REGLAS ANTI-RECHAZO APRENDIDAS
- No escribir "Pixar" ni "Disney": ChatGPT lo rechaza a veces (mensaje de "medidas de protección"). Usar "original 3D-rendered ... storybook illustration".
- Adolescentes: vocabulario escolar y neutro; evitar "sad eyes", "empty classroom", ángulos bajos.
- Si el chat se traba (sin imagen en ~90 s) -> chat nuevo y reenviar. Si repite una composición ya usada -> pedir otra composición.
- Si se adjuntan las fotos base, añadir a cada prompt la línea: "Use the attached reference images for the exact character designs and art style; keep the same faces, hair and clothes."

VOCABULARIO INTERACTIVO — OBLIGATORIO, NO SE PUEDE OMITIR (debe funcionar EXACTAMENTE como en week15.json)
******************************************************************************
Las imágenes de ChatGPT NO llevan texto, pero la lectura sí lleva el vocabulario interactivo, y eso NO se toca ni se olvida.
Reglas (idénticas a week15.json; week21.json ya fue verificado y las cumple):
1. Cada grado tiene EXACTAMENTE 10 entradas en "vocabulary", con el formato {"word": "...", "definition": "definición en inglés (traducción)"}.
2. "practiceWords" contiene las MISMAS 10 palabras, en el MISMO orden que "vocabulary".
3. Cada palabra del vocabulario aparece marcada con <b>palabra</b> dentro de "sentences[].html" de las páginas (una vez cada una). Esa marca <b> es lo que la vuelve interactiva (tocar/clic -> resalta, muestra la definición y la pronuncia). La comparación es sin distinguir mayúsculas (ej.: <b>Permission</b> = "permission").
4. NO quitar, renombrar ni mover las etiquetas <b>; NO convertir "html" en texto plano; NO cambiar "word"/"definition" ni volver al esquema viejo (legacySentenceSchema: false).
5. Respetar todo el código base del audio: "contentPolicy" igual (tts: "Web Speech API / SpeechSynthesis", manualAudioFiles: false). No se agregan archivos de audio ni se modifica el lector.
6. Las rutas de imagen del JSON NO cambian: ../assets/images/week21_gradeXX_cover.webp y ../assets/images/week21_gradeXX_pageNN.webp.
Checklist final por grado: [ ] 10 vocabulary  [ ] practiceWords = vocabulary  [ ] 10 <b> en las oraciones  [ ] audio intacto  [ ] imágenes con nombre exacto.
